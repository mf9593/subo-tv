🚀 快速开始

三步搞定，开始观看

1

安装 APK

下载 app-debug.apk 并通过 ADB 安装到电视盒子：
adb install -r app-debug.apk

2

打开 Web 后台

在电视上打开速播，菜单 → 频道导入，电视屏幕会显示二维码和 IP 地址。

3

导入直播源

手机浏览器访问电视 IP，输入直播源 URL 或上传文件，点击添加即可。
