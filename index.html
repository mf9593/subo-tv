Quick Start

🚀 三步开始观看

从安装到导入直播源，最快 1 分钟搞定

1

安装 APK

从 GitHub Releases 下载 subo-tv-v1.0.0.apk，或用 ADB 安装：
adb install -r subo-tv-v1.0.0.apk

2

打开 Web 后台

在电视上打开速播，按 菜单键 → 频道导入，屏幕会显示二维码和 IP 地址。

3

导入直播源

手机浏览器访问电视 IP（如 192.168.1.10:8080），粘贴 M3U/M3U8/TXT 源地址或上传文件，点击添加即可。
